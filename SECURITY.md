# Security · Sicurezza

**English.** If you find a security problem — for example a way to read a
library without its password, or a way for the program to send data it
shouldn't — please **do not open a public issue**. Report it privately from
[this form](https://github.com/LorenzoDainelli/local-ai-frame-classifier-rilasci/security/advisories/new). You will get an answer as
soon as possible, and the fix will be credited to you if you wish.

**Italiano.** Se trovi un problema di sicurezza — per esempio un modo di
leggere un archivio senza la password, o un modo in cui il programma manda
dati che non dovrebbe — **non aprire una segnalazione pubblica**. Segnalalo in
privato da [questo modulo](https://github.com/LorenzoDainelli/local-ai-frame-classifier-rilasci/security/advisories/new). Riceverai una
risposta il prima possibile e, se vuoi, la correzione porterà il tuo nome.

Only the latest version receives security fixes. · Le correzioni di sicurezza
arrivano solo sull'ultima versione.
