#     python -m officina modelli --scarica tutti

# Su Windows con una scheda NVIDIA, torch va preso dall'indice di PyTorch

#
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
#
# Senza CUDA funziona lo stesso, sul processore, e sara' circa venti volte
# piu' lento (regola 71).
#
# UNA NOTA ONESTA SUI NUMERI DI VERSIONE QUI SOTTO. Le versioni di

# contro l'elenco di PyPI: esistono tutte. Il primo giro le aveva prese di

# questo puo' sbagliare.
