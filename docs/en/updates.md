# Updates

[← Back](../../README.md) · [Italiano](../it/aggiornamenti.md)

You never need to download a new version by hand. Each time it starts, the
program asks GitHub whether there is a newer one.

## While the program is in beta

1. It finds the new version and downloads it in the background while you
   work.
2. It checks the file's fingerprint. A file that doesn't match is thrown
   away.
3. The next time you open the program, it installs the update and reopens by
   itself.

## Final versions

When a final version comes out, a strip at the top of the window asks you:

- **Aggiorna** (update): installs it now;
- **Rifiuta** (decline): leaves it pending. You can install it later from
  **Impostazioni → Il programma → Aggiornamenti** (Settings → The program →
  Updates).

## What an update touches

Only the program. Your library, labels, categories, models and settings stay
exactly where they are. Your photos are never touched, by updates or by
anything else.

## Where the versions come from

From this page's [releases](https://github.com/LorenzoDainelli/local-ai-frame-classifier-rilasci/releases), and nowhere else. Every version
comes with its `.sha256` fingerprint, which the program checks before
installing.
